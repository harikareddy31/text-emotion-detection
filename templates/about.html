About EmotionAI

A machine learning project for detecting emotions from natural language text.

What is Text Emotion Detection?

Text Emotion Detection is a Natural Language Processing task that identifies the emotional meaning expressed in written text.

How Does Our System Work?

The system converts text into numerical features using TF-IDF and then uses a trained machine learning classification model to predict the emotion.

Supported Emotions

The current system supports Joy, Sadness, Anger, Fear, Surprise and Love.
